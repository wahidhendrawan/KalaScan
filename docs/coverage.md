## Supply-chain attack vectors

The attack tree of Ladisa et al., *SoK: Taxonomy of Attacks on Open-Source Software Supply Chains* (IEEE S&P 2023), ids as in [SAP/risk-explorer-for-software-supply-chains](https://github.com/SAP/risk-explorer-for-software-supply-chains).

- **direct**: a check looks for the vector itself.
- **partial**: a check sees a side effect of the vector, or one form of it.
- **gap**: visible in a package or its listing, and nothing checks it yet.
- **payload only**: a published package does not show how the code got in. Only what the injected code does can be seen (behaviour rules, chains, `kalascan diff`).
- **out of scope**: happens where a package scan does not look (a network path, a build host, a person).

50 vectors: 7 direct, 20 partial, 1 gap, 6 payload only, 16 out of scope.
